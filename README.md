# Laba1.Kuz_V
# Лабораорная работа №1 по продвинутому использованию NumPy.

## Задачи

1. **Числа с плавающей точкой** — исследование ограничений float32/float64
2. **Индексация и broadcasting** — работа с массивами NumPy
3. **Memory-mapped файлы** — оптимизация кэша и работа с большими данными
4. **Разреженные матрицы** — форматы CSR, CSC, COO
5. **Cython** — написание нативных расширений
