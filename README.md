# Lab3.Kuz_V
# Лабораторная работа №3 по форматам хранения данных в Pandas.

## Задачи

1. **Создание DataFrame** — подготовка данных для сохранения во всех форматах
2. **CSV** — сохранение, чтение, проблемы с типами, оптимизация через dtype/parse_dates/usecols
3. **JSON** — вложенные структуры, ориентации records/columns/index/split, json_normalize
4. **Parquet** — сжатие snappy/gzip/brotli, column pruning, сохранение типов
5. **HDF5** — хранение нескольких объектов, форматы fixed/table, запросы через where
6. **Сводный отчёт** — сравнение метрик, рекомендации по выбору формата
